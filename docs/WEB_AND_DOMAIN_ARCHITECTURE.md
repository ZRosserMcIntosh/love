# Web and domain architecture

## Recommendation

Use **love.railgun.chat** as the initial public home.

That framing is appropriate while Agapodynamics remains an experimental
research program developed inside the broader Railgun laboratory. It avoids
prematurely presenting the idea as an established independent discipline.

Suggested routes:

~~~text
love.railgun.chat/
love.railgun.chat/theory
love.railgun.chat/math
love.railgun.chat/math/functions
love.railgun.chat/calculator
love.railgun.chat/examples/six-month-project
love.railgun.chat/methods
love.railgun.chat/claims
love.railgun.chat/research
love.railgun.chat/about
~~~

Future technical domains, only when needed:

~~~text
api.love.railgun.chat
docs.love.railgun.chat
~~~

Do not split the public experience across subdomains prematurely. Routes are
easier to maintain, search, and explain until the API or documentation becomes
genuinely independent.

## Relationship to zrossermcintosh.com

The personal site should explain the origin, motivation, and continuing
notebook; it should not be the canonical location of scientific definitions.

Suggested eventual routes:

~~~text
zrossermcintosh.com/lab/agapodynamics
zrossermcintosh.com/ramblings
zrossermcintosh.com/ramblings/agapodynamics-origin
~~~

The “Rosser's Insane Ramblings” section can contain dated hypotheses,
provocations, thought experiments, sketches, failed ideas, and the capacitor-
to-love chain of reasoning. Each entry should link to the formal claim ledger
when an idea graduates from rambling to testable proposition.

Canonical-source rule:

- Personal origin and unfiltered notebook: zrossermcintosh.com
- Current formal framework and calculator: love.railgun.chat
- Source code and version history: github.com/ZRosserMcIntosh/love

## Future independent domain

Consider a standalone Agapodynamics domain only after:

- a literature review survives hostile review;
- the name survives collision and trademark checks;
- at least one measurement protocol exists;
- independent researchers show interest; and
- the project can stand apart from its founder's personal story.

Until then, love.railgun.chat is both memorable and intellectually honest.
